# Правила проекта

## .agents

`.agents/` управляется пользователем. Не редактировать и не удалять файлы в этой папке.

Если для задачи нужно изменить файл в `.agents/`, сообщить пользователю точный путь и готовый текст для замены, добавления или удаления. Не просить менять ACL или выдавать права.

## Рабочие заметки

Изменяемый контекст проекта вести в `agent-notes/`:

- `architecture.md` — текущая архитектура;
- `context.md` — решения и ограничения;
- `todo.md` — только незавершённые задачи.

`agent-notes/` локальный и не коммитируется. После завершения работы обновлять заметки и убирать выполненные пункты из `todo.md`.
