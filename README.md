# LaterTube

Локальное Chrome-расширение для собственного списка видео без подписки YouTube Premium.

## Установка

1. Откройте в Chrome страницу `chrome://extensions`.
2. Включите **Режим разработчика** справа сверху.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите эту папку: `YoutubeWatchLaterPlugin`.
5. Закрепите расширение через значок пазла на панели Chrome.
6. Обновите уже открытые страницы YouTube.

## Использование

- На странице видео нажмите **Смотреть позже** под роликом.
- На главной YouTube откройте меню `⋮` у ролика и выберите **Смотреть позже (мой список)**.
- Нажмите **Мои видео** в верхней панели YouTube или обычным кликом по иконке расширения, чтобы открыть сетку сохранённых роликов.
- Включите **RemoveOnPlay** на странице списка, чтобы ролик автоматически удалялся из списка при открытии. Состояние переключателя сохраняется между запусками Chrome.
- Сортируйте список отдельно по дате добавления, дате публикации видео, названию или длительности. Точная дата видео берётся со страницы просмотра; на карточках YouTube используется приблизительная дата из текста вроде «2 дня назад». Старые записи без сохранённой даты видео располагаются в конце соответствующей сортировки.
- Доступна сортировка по количеству просмотров и случайный порядок. Случайный порядок создаётся заново при каждом открытии страницы списка и не меняется самопроизвольно, пока страница открыта.
- Нажмите правой кнопкой по иконке расширения и выберите **Добавить все YouTube-видео в список и закрыть вкладки**. Расширение добавит открытые страницы роликов и закроет только эти вкладки; главная YouTube, каналы и результаты поиска останутся открытыми.
- Внизу страницы списка находится необязательная кнопка **Сказать спасибо**. Она показывает адреса для добровольной поддержки в USDT через сети TRON (TRC20) и BNB Smart Chain (BEP20). Поддержка не открывает дополнительных функций.
- Кнопка **Сохранить** скачивает резервную копию списка в читаемый файл `LaterTube-backup-YYYY-MM-DD.txt`. Кнопка **Загрузить** объединяет резервную копию с текущим списком и пропускает дубликаты. Также можно загрузить обычный текстовый файл со ссылками YouTube.

Все данные хранятся только локально в профиле Chrome (`chrome.storage.local`).

[Политика конфиденциальности](https://glebster51.github.io/LaterTube/)

Интерфейс автоматически использует язык Chrome. В комплект входят английская, русская и испанская локализации; для остальных языков используется английский.
