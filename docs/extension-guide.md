# LaterTube

Chrome-расширение и Android-приложение для личного списка видео без подписки YouTube Premium. Активный список и раздел «Просмотрено» синхронизируются через Firebase Realtime Database на бесплатном тарифе Spark; карта, кабель, ADB, одна Wi-Fi сеть и постоянно работающий компьютер не нужны.

## Первичная настройка Firebase

1. Создайте Firebase-проект на тарифе **Spark** и не подключайте Cloud Billing.
2. В **Authentication → Sign-in method** включите **Email/Password**.
3. Создайте **Realtime Database** и примените правила из `database.rules.json`.
4. В настройках проекта создайте Web app и скопируйте Web API key.
5. Скопируйте `firebase-config.example.js` в `firebase-config.local.js` и заполните `apiKey` и `databaseUrl`.
6. Скопируйте `android/firebase.properties.example` в `android/firebase.properties` и заполните те же значения.

Оба заполненных файла находятся в `.gitignore`. API key Firebase не является паролем, но его не публикуем, чтобы посторонние не расходовали квоту проекта. Доступ к данным защищают правила базы: пользователь может читать и изменять только `/users/<свой uid>`.

## Установка расширения

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `YoutubeWatchLaterPlugin`.
4. Закрепите LaterTube через значок пазла и обновите уже открытые страницы YouTube.
5. Откройте список, нажмите **Войти**, затем создайте отдельный аккаунт LaterTube либо войдите в существующий.

Используйте одинаковые email и пароль в расширении и Android-приложении. Пароль клиенты не сохраняют: после входа остаётся только токен Firebase, на Android он зашифрован Android Keystore.

Если пароль забыт, на форме входа нажмите **Забыли пароль?**: расширение или Android-приложение самостоятельно запросит у Firebase письмо для установки нового пароля.

## Использование

- На странице видео нажмите **Смотреть позже** под роликом.
- На главной YouTube откройте меню `⋮` у ролика и выберите **Смотреть позже (мой список)**.
- При добавлении кнопка или пункт меню сразу показывает вращающийся индикатор. После ответа Firebase появляется зелёное подтверждение; для меню `⋮` результат также показывается отдельным коротким уведомлением.
- Нажмите **Мои видео** в верхней панели YouTube или по иконке расширения, чтобы открыть список.
- Опция **В просмотренное при открытии** сначала записывает перенос в Firebase, а затем открывает видео.
- Вкладка **Просмотрено** содержит просмотренные и вручную убранные из списка ролики. Их можно открыть без изменения раздела, вернуть в активный список или удалить из Firebase безвозвратно после подтверждения.
- Список сортируется по дате добавления, дате публикации, просмотрам, названию, длительности или случайно.
- Команда в контекстном меню иконки добавляет открытые YouTube-видео в список и закрывает только вкладки с видео.
- **Сохранить** скачивает `LaterTube-backup-YYYY-MM-DD.txt`; **Загрузить** объединяет резервную копию с облачным списком и пропускает дубликаты.

В Firebase у каждого аккаунта есть отдельные JSON-документы `active` и `history` внутри `/users/<uid>`. Все изменения выполняются с проверкой версии, поэтому одновременные записи с разных устройств не затирают друг друга. Расширение хранит локальный UI-снимок списка и сразу показывает его при открытии. При открытии страницы списка и при возврате в уже открытую вкладку расширение автоматически запрашивает только `updatedAt`; полный JSON загружается лишь при изменении версии. Firebase остаётся источником истины. Превью кэшируются отдельно и не исчезают во время фоновой проверки.

## Android

1. Соберите APK после заполнения `android/firebase.properties`: `android\gradlew.bat :app:assembleDebug`.
2. Установите `android/app/build/outputs/apk/debug/app-debug.apk`.
3. Войдите с теми же данными, что и в расширении.
4. При старте приложение сразу показывает приватный локальный снимок списка и проверяет `updatedAt` на сервере. Полный JSON загружается только при изменении версии.
5. Для ручной проверки потяните список вниз, находясь в самом верху, до запуска вращающегося индикатора; также доступна кнопка **Обновить сейчас**. Возврат из YouTube сам по себе сетевой запрос не запускает.
6. Перенос в просмотренное, возврат и безвозвратное удаление записывают изменение в Firebase сразу.

[Политика конфиденциальности](https://glebster51.github.io/LaterTube/)

Интерфейс расширения автоматически использует язык Chrome. В комплект входят английская, русская и испанская локализации; для остальных языков используется английский.
